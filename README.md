## 🤖 **КОМАНДЫ БОТА**

- `/start` — запуск бота
- `/add_card` — добавить карту
- `/webapp` — веб-приложение
- `/city` — выбор города
- `/help` — справка
- `/policy` — политика
- `/clear_cache` — очистка кэша
- `/tariffs` — тарифы

## 🔧 **ФУНКЦИИ СИСТЕМЫ**

### ✅ **РАБОТАЕТ:**
- Главное меню для всех ролей
- Личные кабинеты пользователей и партнеров
- Категории и подкатегории
- Команды бота
- Веб-кабинеты (WebApp)
- Система тарифов
- Мультиязычность (RU, EN, VI, KO)
- Реферальная система
- Геймификация
- API endpoints

### ⚠️ **ТРЕБУЕТ ДОРАБОТКИ:**
- Админские функции (нет переводов)
- Супер-админские функции (нет переводов)

### 🌐 **ВЕБ-КАБИНЕТЫ**
- Пользовательский: `webapp/user-cabinet.html`
- Партнерский: `webapp/partner-cabinet.html`
- Админский: `webapp/admin-cabinet.html`

### 📡 **API ENDPOINTS**
- `/api/user/*` — пользователи
- `/api/partner/*` — партнеры
- `/api/admin/*` — админы
- `/api/moderation/*` — модерация
